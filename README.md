 Employee-Salary-Calculator-CPP

 Description
This is a simple C++ program that calculates the monthly salary of five employees based on their hourly wages.

Features
- Takes employee name as input.
- Takes hourly wages as input.
- Takes employee designation as input.
- Calculates monthly salary.
- Uses classes and objects in C++.

Salary Formula
Monthly Salary = Hourly Wages × 40 × 4

Language
C++

Concepts Used
- Classes and Objects
- Member Functions
- Data Members
- User Input and Output
